# Xazura Creators Bot

Бот для креаторов @XazuraShop (TikTok).

## Меню
- **📝 Подать заявку** → за видео или за комментарии
- **🔄 Обменять комментарии** → баланс комментариев меняется на Telegram-аккаунт из прайса
- **👤 Профиль** → аккаунты, реквизиты, баланс, уровень
- **📋 Мои заявки** → все заявки и обмены со статусами
- **ℹ️ Информация** → тарифы, правила, топ месяца, гайды, поддержка

## Как работает
- **Видео:** 1) ссылка на TikTok-аккаунт, 2) ссылки на видео (видео с другого аккаунта и повторы бот не берёт),
  3) одна запись экрана, где по порядку показаны 4 раздела статистики, 4) способ оплаты и реквизиты («как в прошлый раз» подставляет прошлые).
  Админ смотрит статистику, жмёт «👁 Просмотры» и вводит число, сумма считается сама (ставка × уровень).
  Статусы: на проверке → одобрена, ждёт выплаты → выплачено.
- **Комментарии:** от 40 скриншотов + запись экрана истории комментариев. Админ зачисляет все или часть на баланс.
- **Обмен (автовыдача):** креатор выбирает страну, бот сразу покупает аккаунт на LOLZ (`lolz.py`, токен `LOLZ_TOKEN`
  тот же, что в магазине) и показывает номер с кнопкой «🔑 Получить код». Аккаунты лежат в «📱 Мои аккаунты».
  Если лотов нет или на LOLZ кончились деньги, комментарии сразу возвращаются, админу приходит уведомление.
  Позиции прайса без кода страны выдаются вручную: админ отправляет аккаунт и жмёт «Аккаунт выдан».
- **Прайс обмена:** `/admin` → «🏷 Прайс обмена», строка `80 ID 41 🇮🇩 Индонезия [+62]`
  (комментарии, код страны, потолок закупки ₽, название). Мин. рейтинг продавца: `/set lolz_min_rating 50`.

## Автоматика (`scheduler.py`, проверка раз в 30 минут)
- **Бонусы топа:** 1-го числа топ-3 прошлого месяца получают бонусы (`top_rewards`), они сразу попадают в «К оплате».
  Победителям приходит поздравление, всем креаторам итоги. Бонусы не засчитываются в топ следующего месяца.
- **Напоминание админам:** если заявки ждут проверки больше 24 ч (не чаще раза в 12 ч).
- **Напоминание креаторам:** кто не подавал заявок `nudge_days` дней, днём с 11 до 21 (0 = выключено).

## Реферальная программа (кнопка «👥 Пригласить друга»)
Ссылка `t.me/бот?start=ref_ID` засчитывается только новичку (первые 10 минут в боте). Пригласившему:
- `ref_bonus` 💬 разово, когда друг получит первую выплату или зачисление;
- `ref_comments_pct` % от каждого зачисления комментариев друга (сразу на баланс);
- `ref_video_pct` % от каждой выплаты другу за видео: рубли копятся и от `ref_min_payout` ₽ сами уходят в «К оплате».
С бонусов топа и реферальных выплат доля не начисляется.

## Надёжность
- Начатые заявки хранятся в базе (`storage.py`): перезапуск бота их не сбрасывает.
- Если бот упал посреди покупки на LOLZ, при старте такие обмены уходят админу на проверку.
- Лог `bot.log` ротируется: не больше 3 файлов по 5 МБ.

## Админ-группа
1. Добавь бота в группу админом и напиши там `/bind`. Без группы заявки приходят админам в личку.
2. Пруфы по кнопке приходят в личку тому, кто нажал, поэтому каждому админу нужно один раз написать боту `/start`.

## Админка
- `/admin`: заявки, «К оплате», «Выдать аккаунты», статистика, поиск креатора (бан, правка выплат и баланса),
  рассылка, прайс обмена, примеры комментариев, выгрузка в Excel, настройки
- `/set ключ значение`: ставка, минималки, курсы, `top_rewards 1000,500,250`, `ref_bonus 10`, `nudge_days 7`
- `/bind`, `/unbind`, `/cancel`

## Запуск на ПК
Двойной клик по `run.bat`. Лог пишется в `bot.log`.

## Файлы
- `.env`: токен, ID админов, канал, бот поддержки, ссылка на группу
- `texts.py`: все тексты и правила
- `config.py`: уровни, значения по умолчанию, стартовый прайс
- `data.db`: база
- `_old_backup/`: старая версия бота

## Хостинг (VPS, Docker)
```
# скопируй папку на сервер (без venv и _old_backup), положи рядом .env
mkdir -p data && cp data.db data/   # если переносишь базу с ПК
docker compose up -d --build
docker compose logs -f
```
